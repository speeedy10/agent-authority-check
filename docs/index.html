Agent Authority Check

A zero-dependency static preflight for MCP servers and tool-using AI agents. It highlights authority-bearing code for human review without pretending scanner hits are vulnerabilities.

Command executionFind tool-adjacent process execution primitives.
Filesystem authoritySurface read/write capabilities near agent tools.

Secrets & environmentIdentify credential-adjacent configuration surfaces.
SOURCE → TRANSFORM → SINK → PRIVILEGE → CONSEQUENCE A static hit is an observation. Promotion requires actual reachability and consequence proof inside an owned or explicitly authorized boundary.

Quick start

python scan.py /path/to/repo --json report.json
